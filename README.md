# StudyFlow 📚

**StudyFlow** is a desktop application built with C# and .NET MAUI to organize study tasks and track learning time.

I created this app using **C# and .NET MAUI** as a practical project to apply what I am learning and experiment with building graphical desktop applications.

> 🚀 This project is evolving as a personal learning product, growing from a simple task planner into a full study management tool.

---

## ✨ Features

### 📝 Tasks

StudyFlow lets you create and manage your study tasks easily.

- task title and description;
- deadlines;
- mark tasks as completed;
- view all tasks;
- delete tasks;
- local data persistence between app launches.

### 🎯 Focus Mode

A dedicated mode for distraction-free study sessions.

You can:

- choose a task;
- set a session duration;
- start and pause the timer;
- end the session early;
- add notes after studying;
- check the actual active focus time.

Paused time does not count toward your study time.

### 📊 Statistics

StudyFlow keeps track of your completed focus sessions.

You can monitor:

- total study time;
- individual study sessions;
- focus history;
- learning progress.

### 🎯 Study Goals

Set your own goals and track your progress over time.

This helps turn studying from a random list of tasks into a systematic process.

### 📅 Schedule

A separate section to plan study activities and keep track of upcoming deadlines.

### 🔥 Study Streak

The app tracks your daily study streak to help build consistency and regular habits.

### 💾 Data Storage

All data is saved locally on your device.

The app does not require an external database or server for basic use.

## 🚀 Getting Started

### Requirements

To run this project, you need:

- Windows;
- Visual Studio 2022 or newer;
- .NET SDK;
- **.NET MAUI** workload installed.

### Setup

1. Clone the repository.
2. Open the `.sln` or `.csproj` file in Visual Studio.
3. Make sure the .NET MAUI workload is installed.
4. Select your target platform.
5. Run the app.
